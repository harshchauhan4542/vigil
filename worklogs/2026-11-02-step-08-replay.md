## What was done

- `packages/replay`:
  - `transport.ts` `createReplayFetch({ mode, kind, store, record, secrets })`: a `fetch` drop-in for both the PayPal client and the Anthropic SDK. Live = real call (optionally recorded). Replay = served by key; a miss throws `ReplayMissError` (never falls back to live). PayPal OAuth is never recorded and is answered locally in replay mode.
  - Keys: PayPal `sha256(METHOD + path with sorted query + canonical body)` (ignores auth and `PayPal-Request-Id`); Claude `sha256(canonical {model, system, messages, tools})`. Per-occurrence keys so the same GET before and after a capture replays both answers; replay falls back only to an earlier occurrence.
  - `scrub.ts`: drops all request headers, keeps only `content-type` / `paypal-debug-id` / `request-id` response headers, replaces secret-looking keys (tokens, passwords, card numbers…) and every known secret value in JSON and SSE bodies.
  - `store.ts`: `MemoryFixtureStore`, `FileFixtureStore` (`fixtures/recordings/<kind>/<key>.json`), `LayeredFixtureStore`.
- `packages/db/src/recordings.ts`: `createDbFixtureStore(db)` over the `recordings` table.
- Config: `RECORD`, `FIXTURES_DIR`.
