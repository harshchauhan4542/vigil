## What was done

- `packages/agent/src/loop.ts` `runAgent` / `triageException`: manual tool loop (needed for the replay transport, an 8-turn cap and a persisted trace). Per turn: `client.messages.stream(...)` → `finalMessage()`; strict client tools; `tool_choice: auto` (forced tool use is a 400 on `claude-opus-5-5`); `thinking: {type: "adaptive"}`; frozen system prompt with `cache_control`; full assistant content (thinking blocks included) appended unchanged; parallel tool calls run concurrently and return in one user message; `pause_turn` resumes; `refusal` / `max_tokens` stop. Every run saved to `agent_runs` (tokens, turns, full trace, prompt hash).
- `tools-read.ts`: `get_exception` (incl. customer notes, wrapped untrusted), `get_authorization`, `get_capture` (live PayPal via `reads`), `get_ledger_entries` (memos untrusted), `get_policy_limits` (injected data), `get_settlement_trail`.
- `tools-propose.ts`: `propose_*` for 9 actions; params schema from `@vigil/core` + `evidence_refs` / `rationale ≤ 600` / `confidence`; the only write is `insertDraftProposal` (DRAFT).
- `tool.ts`: one Zod schema per tool → Claude JSON Schema (`z.toJSONSchema`) with unsupported strict-mode keywords stripped (lengths, ranges, patterns); Zod still enforces them before a tool runs, and invalid input goes back to the model as `is_error`.
- `untrusted.ts`: `<untrusted source="…">` wrapper that neutralises forged closing tags.
- `toolkit-adapter.ts` (subpath `@vigil/agent/toolkit`): `@paypal/agent-toolkit/openai` with read-only actions only (`shipment: {get}`), filtered again by name, non-strict. New ESLint quarantine: only this file may import the toolkit.
- `client.ts` `createClaudeClient`: Anthropic SDK 1.3.0 over the replay transport (`maxRetries: 0` in replay).
- `testing.ts` (subpath `@vigil/agent/testing`): scripted fake Claude Messages API that streams real SSE.
- `@vigil/replay`: LLM keys now replace UUIDs with first-appearance placeholders, and replay maps recorded UUIDs back to the current run's, so a recording replays on a fresh database.
