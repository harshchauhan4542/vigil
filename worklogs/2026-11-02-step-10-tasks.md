  - `tasks/execute-proposal.ts` (LLM-free): verify token + recomputed params hash + matching approval → consume token (single use) → reserve `PayPal-Request-Id` in `idempotency_keys` **before** the call → call → record HTTP status / PayPal status / `debug_id`. APIs without a request id (tracking, suspend) use check-before-act and never call twice. Internal actions: `journal_entry` writes one ledger correction, `dismiss` closes the exception.   - `tasks/index.ts`: `detect_exceptions` (fans out triage), `triage_exception` (agent → policy per DRAFT → AWAITING_APPROVAL or ESCALATED), `settle_check`, `reconcile_window`, `reseed_demo` (seeder cohort + sweep), `buildHandlers`.

- `@vigil/db`: `countOtherOpenProposals`, `executedCentsSince` (one row per proposal), `listProposalsByStatus`, `setProposalPolicy`, `advanceException`, agent-run repos, mirror update helpers.
